# 神瞳文案手工覆盖区

放在这里的 `.md` 会**覆盖**站点上对应神瞳的说明与截图。没放的就用官方原始数据。

文件用 **AMDL**（本项目的 Markdown 超集）写：普通 Markdown 全都能用，
另外支持提示框、分栏、图集、折叠、标签页、链接卡、行内任意样式。
完整语法见仓库根目录 `AMDL.md`，**速查见同目录 `_AMDL速查.md`**。

## 怎么用

1. 桌面 `shentong/` 里是全量文件，共 **1644 个**：
   神瞳 1331 个（`feng1` … `bing140`）+ 区域特殊收集物 313 个（`feihong` 绯红玉髓 80、
   `liuming` 流明晶石 83、`jianwen` 键纹 62、`jiyi` 技忆团块 30、`yidi` 影生翼滴 58）
2. 挑要改的，**复制**到这个目录，改内容
3. 发布：`python scripts/build_upstream.py --note "说明" --tags 点位 --publish`
4. 站点下次检查更新时会自动拉取并生效（约 2–5 分钟 CDN 刷新）

改之前建议先同步一次，让文件里的官方原文/地区/图层是最新的：

```bash
node scripts/oculi_md.mjs sync            # 同步桌面 shentong/，自动备份、保留手写正文
node scripts/oculi_md.mjs sync --dry-run  # 只看会改什么
```

## 文件格式

```markdown
# 风神瞳 #1

- 编号：1
- 类型：风神瞳
- 地区：蒙德
- 图层：地表
- 点位：24676
- 截图：
- 原文哈希：54f4e995

## 说明

完成主线任务《书页里的电火花》后自动获得

::: note tone=warn title="注意"
到达前先点亮七天神像。
:::
```

- `- 点位：` 是这个神瞳的唯一编号，**别删**（删了会按文件名 `feng1` 反查，也能救回来）
- `## 说明` 下面的全部内容就是站点上显示的说明，可以是纯文字，也可以带任意 AMDL 语法
- `- 截图：` 填图片地址（留空表示不覆盖）
- `- 原文哈希：` 是**同步指纹**，用来判断「官方原文变没变」，人不用管；
  删掉也能用，只是下次同步会把当前官方原文当成基线
- 坐标不在这里改，它是地图权威数据

## 注意

- 文件名保持 `元素拼音+编号`：`feng`风 `yan`岩 `lei`雷 `cao`草 `shui`水 `huo`火 `bing`冰 `yue`月、
  `feihong`绯红玉髓 `liuming`流明晶石 `jianwen`键纹 `jiyi`技忆团块 `yidi`影生翼滴
- 本目录的 md **不会**被上游发布流程当成普通资源清单管理，可以放心增删
- 以 `_` 开头的文件会被忽略（比如本说明和速查）
- 只放「要覆盖的点位」：既没正文也没截图的文件会被构建器跳过
- 忘了删「（暂无说明，可在此补充）」也没关系，这一行在编译期会被摘掉
- 这里写的是**文本与样式**，不执行脚本：裸 HTML 按文字显示，
  `javascript:` 链接与 `url(...)` 样式会被丢弃（上游内容不可信，客户端只做白名单渲染）
