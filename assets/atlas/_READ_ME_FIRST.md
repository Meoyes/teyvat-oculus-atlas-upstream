# 神瞳文案手工覆盖区

放在这里的 `.md` 会**覆盖**站点上对应神瞳的说明与截图。没放的就用官方原始数据。

## 怎么用

1. 桌面 `shentong/` 里是全量文件（`feng1.md` … `bing140.md`，共 1331 个）
2. 挑要改的，**复制**到这个目录，改内容
3. 发布：`python scripts/build_upstream.py --note "说明" --tags 点位 --publish`
4. 站点下次检查更新时会自动拉取并生效（约 2–5 分钟 CDN 刷新）

## 文件格式

```markdown
# 风神瞳 #1

- 编号：1
- 类型：风神瞳
- 地区：蒙德
- 图层：地表
- 点位：24676
- 截图：

## 说明

完成主线任务《书页里的电火花》后自动获得
```

- `- 点位：` 是这个神瞳的唯一编号，**别删**（删了会按文件名 `feng1` 反查，也能救回来）
- `## 说明` 下面的全部内容就是站点上显示的说明，可以写多段
- `- 截图：` 填图片地址（留空表示不覆盖）
- 坐标不在这里改，它是地图权威数据

## 注意

- 文件名保持 `元素拼音+编号`：`feng`风 `yan`岩 `lei`雷 `cao`草 `shui`水 `huo`火 `bing`冰
- 本目录的 md **不会**被上游发布流程当成普通资源清单管理，可以放心增删
- 以 `_` 开头的文件会被忽略（比如本说明）
